# 公共机制

这里记录跨系统共用的架构机制。它们不因被多个系统使用就单独归类为业务子系统。

| 机制 | 说明 |
| --- | --- |
| [Model 机制](Model机制.md) | 内容行为内聚、公共基类与专属入口的分工。 |
| [Hook 派发机制](Hook派发机制.md) | 参与者获取、有效性判断与方法派发。 |
| [Command 执行机制](Command执行机制.md) | 统一状态变更入口、校验和结果反馈的讨论。 |

具体机制选择与契约见 [ADR 索引](../../README.md)，实际业务能力见 [子系统目录](../Subsystems/README.md)。
