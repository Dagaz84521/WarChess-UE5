# ADR-001：选择 Hook & Model 架构

> 状态：已确定
>
> 本记录确认核心架构方向，不表示具体接口已确定或代码已实现。

## 1. 背景

项目使用 Unreal Engine 和 C++ 开发回合制战棋框架，处于架构设计初期。目标是先完成 MVP，再形成模块化、易扩展、便于理解和测试的开源框架。

## 2. 面临的问题

需要选择组织战斗状态和内容规则的核心架构，使内容行为内聚，并支持规则扩展，同时控制初期设计范围。

## 3. 候选方案

- 以原生 GAS 作为核心战斗架构。
- 参考 Hook & Model，构建适合回合制战棋的轻量化规则系统。

以上是本决策涉及的方向对照，不表示已经完成 GAS 的全面评估或性能对比。

## 4. 最终决定

主要参考《杀戮尖塔 2》的 Hook & Model 架构，不采用原生 GAS 作为核心战斗架构。计划围绕 Model、Hook、Command 等概念组织战斗逻辑，具体职责和协作机制后续设计。

## 5. 决策理由

该方向符合已明确的行为内聚、规则可扩展和轻量化目标，并允许围绕 MVP 的实际回合制需求逐步定义契约。理由是项目方向与设计目标的匹配，不是已经验证的性能或开发效率结论。

## 6. 代价与影响

预期需要自行设计和维护状态管理、规则扩展、执行机制及诊断与测试支持。规则组合的顺序、冲突和生命周期将成为必须解决的问题。

这些是选择自建规则系统的预期工作与风险，实际成本尚未验证；本决策不预设类结构、模块依赖或 Hook 调用实现。
