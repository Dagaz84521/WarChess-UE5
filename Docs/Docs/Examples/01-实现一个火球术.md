> 状态：草案

## 1. 功能目标

以火球术为例，验证 Code-First 如何表达技能行为，以及技能如何参与战斗规则。

当前案例对齐最小 Unit 结构：技能归属由 SkillSet 管理，玩法行为由 SkillModel 的 OnPlay 定义，冷却由 SkillModel 自行管理。本轮仅完善说明，不展开完整施法流程或实现代码。

## 2. 预期游戏行为

拟用于验证：单位施放火球术，对符合技能规则的目标产生伤害，并呈现施法与结果。

火球术的基础伤害强度使用威力 Power。正式计算与结算规则以 [ADR-005：伤害结算流程](../Architecture/Decisions/ADR-005-伤害结算流程.md)为准，技能层确认命中后提交 Direct 请求，由伤害结算读取指定攻防属性。当前契约见 [伤害结算实现](../Implementation/Prototype/伤害结算实现.md)；本案例的具体威力仍待确定。
