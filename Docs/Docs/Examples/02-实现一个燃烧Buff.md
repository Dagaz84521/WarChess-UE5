## 1. 功能目标

以燃烧为例，验证状态效果的施加、持续行为和移除能否被清晰表达和测试。

实例与生命周期归 BuffSet 管理，具体玩法由燃烧 BuffModel 以 Code-First 定义，可在选定的 Hook 时机参与结算。当前只补充职责，不确定伤害公式或 Health 写入方式。

## 2. 预期游戏行为

拟用于验证：单位获得燃烧效果，在约定的时机受到持续伤害；效果按约定条件结束后不再产生该效果的伤害。

持续时间遵循 [Buff 系统](../Architecture/Subsystems/单位系统.md#buff) 已确认的规则：按全局回合计数，在全局回合结束时扣减。这不代表燃烧伤害也必须在回合结束时触发。
