# 扩展一种地形规则：泥地、飞行与占位

> 状态：建议验证案例，未实现。
>
> 当前适用范围：本文的地形内容与经过/停留差异是后续扩展示例，尚未实现。当前搜索器已支持非负整数费用，采用预算桶式 Dijkstra；见 [ADR-010](../Architecture/Decisions/ADR-010-寻路算法确定.md)。算法支持带权边，不代表示例地形内容已经接入。
>
> 依据：[ADR-007](../Architecture/Decisions/ADR-007-移动系统与寻路算法解耦.md)。以下数值仅为测试输入，不确定正式游戏平衡。

## 1. 功能目标

用一张很小的带权地图验证：地形与单位差异由 MoveRule 解释，一次搜索生成预算内最短路径树，同一 Result 既用于范围显示，也用于恢复多个目标的路径。

不加入进入效果、Hook 或动画。

## 2. 输入与规则

使用五个格子 S、A、B、C、G。S 为起点，仅存在以下双向邻接，不存在其他边：

| 路线 | 邻接关系 |
| --- | --- |
| 较短路线 | S ↔ A ↔ G |
| 绕行路线 | S ↔ B ↔ C ↔ G |

这是抽象邻接测试地图，可作为六边形棋盘中的走廊，不依赖某一坐标表示。所有单位移动预算为 3。

| 格子 | 事实 | 步行进入 Cost | 飞行进入 Cost | 停留 |
| --- | --- | --- | --- | --- |
| S | 自身起点，普通地形 | 1 | 1 | 起点目标策略另行确认 |
| A | 泥地 | 4 | 1 | 允许 |
| B | 普通地形，友军占位 | 1 | 1 | 本例允许穿越，不允许停留 |
| C、G | 普通地形，无占位 | 1 | 1 | 允许 |

起点初始费用为 0，不支付进入起点费用。飞行在本例仅忽略泥地惩罚，并不自动忽略占位停留限制。

## 3. 手工期望结果

| 单位 | 预算内最低 Cost | 合法目标（排除起点） | 到 G 的路径与费用 |
| --- | --- | --- | --- |
| 步行 | S = 0，B = 1，C = 2，G = 3；A 不在预算内 | C、G | S → B → C → G，Cost = 3 |
| 飞行 | S = 0，A = 1，B = 1，C = 2，G = 2 | A、C、G | S → A → G，Cost = 2 |

B 必须保留在搜索结果并继续扩展；只在目标筛选时排除。步行选择更多步数但总 Cost 更低的路线，不能按步数代替带权最短路。

## 4. 模块分工

- Board 提供上述邻接、泥地事实与 B 的占位。
- MoveInput 提供单位移动类型与预算。
- MoveRule 解释泥地费用、友军穿越与停留资格。
- PathFinding 获取边并生成完整的 Start、CostMap 与 PreviousMap。
- MoveResolver 基于同一 Result 调用 GetMoveRange / BuildPath，缓存失效时统一重建树。

新增泥地不应要求搜索器出现地形枚举分支；是否用 Model 承载其他地形内容，不在本案例确定。

## 5. 验证步骤

| 场景 | 预期结果 | 状态 |
| --- | --- | --- |
| 步行 / 飞行范围 | 与第 3 节一致 | 待验证 |
| 查询后预览 C、G 并选择 G | 从同一 Result 恢复各目标路径，费用正确，搜索总次数保持一次 | 待验证 |
| 无缓存直接对 G 下令，再查范围 | 先构建并缓存完整最短路径树，再恢复 G 路径；后续范围查询直接复用，总搜索一次 | 待验证 |
| 两种结果操作 | GetMoveRange 只筛选终点，BuildPath 只追溯前驱；都不触发搜索、不删改树 | 待验证 |
| 对 B 下令 | 返回不可停留，即使它可达且预算充足 | 待验证 |
| 将 A 的步行费用改为 1 | 原缓存失效；步行到 G 改为 S → A → G，Cost = 2 | 待验证 |
| 将 B 改为禁止进入 | 原缓存失效；步行在预算 3 内无法到 G | 待验证 |
| 将步行预算改为 2 | 原规则下 G 超预算；不能复用预算 3 的合法目标集合 | 待验证 |
| 查询纯度 | 不改变位置、占位或移动资源，仅允许更新派生缓存 | 待验证 |

若另行验证保留的独立 A*，可将其目标最低费用与本例树结果对照；它不参与上述移动主流程。其启发函数需适用于当前费用规则，不能仅凭六边形坐标距离推定任何配置都正确。
